# Simulado Schaeffler — Treino

Site simples em HTML/CSS/JS, sem dependências.

## Como usar
1. Abra o arquivo `index.html` no navegador; ou
2. Envie os arquivos para um repositório no GitHub e ative o GitHub Pages.

O site possui 30 questões, cronômetro de 2 horas, progresso e correção automática.
